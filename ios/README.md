# MleySoft İK iOS - V91

Bu klasör GitHub/Codemagic üzerinde iOS platformunun izlenmesi için bulunur.
Gerçek Xcode Runner projesi Codemagic macOS build başlangıcında `flutter create --platforms=ios --org com.mleysoft .` ile oluşturulur ve `native_config/configure_ios.py` ile `com.mleysoft.ik` Bundle ID / ikon / izin ayarları uygulanır.

Bu yöntem Windows üzerinde Xcode gerektirmeden kaynak kodun TestFlight için hazırlanmasını sağlar.
