MleySoft IK Native V48

V47'deki hata AGP 9'un eski Android/Kotlin DSL'lerini artik derleme hatasi saymasindan kaynaklaniyordu.
V48 bu gecisi zorlamak yerine Android build zincirini sabit ve uyumlu surumlere pinler:

- Android Gradle Plugin: 8.10.1
- Gradle: 8.11.1
- compileSdk / targetSdk: 36
- JDK / JVM target: 17
- Kotlin: Flutter create tarafindan tanimlanan KGP
- core library desugaring: aktif
- MainActivity: FlutterFragmentActivity

Boylece AGP 9'a ait android.newDsl / built-in Kotlin gecis hatalari build zincirinden cikarildi.
